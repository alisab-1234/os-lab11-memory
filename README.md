## Задание 3
Контрольная проверка: объясните, почему VmSize и VmRSS различаются. 
VmSize - виртуальная память, показывает весь обьем адресного пространства, который программа зарезервировала
VmRSS - резидентная память, показывает сколько из этого обьема реально находится в оперативной памяти в данный момент
VmSize всегда больше, потому что он включает в себя зарезервированную так еще и не использованную память

## Ответы на контрольные вопросы
1. Чем физическая память отличается от виртуальной?
Физическая - реальные чипы в Оперативной памяти
Виртуальная - программный механизм который добаляет часть места на жестком диске
2. Для чего процессу необходимо виртуальное адресное пространство?
Для безопасности и изоляции, чтобы программы не мешали друг другу
3. Чем стек отличается от кучи?
Стек - быстрый, это память для локальных переменных и вызов функции, он очищается автоматически при выходе из функции
Куча - медленный, это память для димамически выделяемых данных, его очищать нужно вручную 
4. Что показывает параметр RSS?
RSS - размер физической оперативной памяти, которую процесс реально занимает в данный момент 
5. Почему VSZ может быть значительно больше RSS?
Потому что vsz оставляет часть памяти на будущее 
6. Чем отличаются free и available в выводе free -h?
free это  пустая память
available  это память которую можно отдать другим программмам прямо сейчас 
7. Что такое page cache и зачем он нужен? 
это кэш файлов в свободной оперативной памяти, нужен чтобы читать файлы с быстрой памяти, а не с медленного диска
8. Какую роль выполняет swap?
область на диске для выгрузки редко используемых данных, когда оперативная память заканчивается
9. Почему после data.clear() значение RSS может не уменьшиться?
Питон удерживает у себя освобожденную память ждя повторного использования, не отдавая ее ос
10. Что произойдёт, если процессу не хватит памяти? 
Сработает ООМkiller, тобиж ядро принудительно убъет самый жирный процесс
11. Для чего предназначен каталог /proc/PID/? 
он нужен для подробного просмотра информации о контретном процессе
12. Как Docker может ограничивать использование памяти контейнером?
Использует механизм cgroup в ядре Линукс для лимита памяти 
13. Зачем файл sample.bin добавлен в .gitignore? Что случилось бы, если бы в репозиторий 
попадали такие файлы?
sample.bin - это большой бинарный файл (32 МБ). Если заливать такие файлы с гит, репозиторий очень быстро раздуется, клонирование и отправка станут медленными и история комитов нечитаемой
14. Почему результаты измерений удобнее хранить в текстовых файлах в Git, чем в 
скриншотах? 
Текст занимает мало места, а скриншоты - это тяжелые бинарные файлы 
15. Зачем эксперимент с Docker выполнялся в отдельной ветке и что даёт Pull Request?
Ветка защищает main от ошибок, PR нужен для проверки кода и безопасного слияния
