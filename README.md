## Задание 3
Контрольная проверка: объясните, почему VmSize и VmRSS различаются. 
VmSize - виртуальная память, показывает весь обьем адресного пространства, который программа зарезервировала
VmRSS - резидентная память, показывает сколько из этого обьема реально находится в оперативной памяти в данный момент
VmSize всегда больше, потому что он включает в себя зарезервированную так еще и не использованную память
