## Задание 3
Контрольная проверка: объясните, почему VmSize и VmRSS различаются. 
VmSize - виртуальная память, показывает весь обьем адресного пространства, который программа зарезервировала
VmRSS - резидентная память, показывает сколько из этого обьема реально находится в оперативной памяти в данный момент
VmSize всегда больше, потому что он включает в себя зарезервированную так еще и не использованную память

## Ответы на контрольные вопросы
1. Почему программа может успешно работать на хосте, но завершаться в контейнере?
На хосте доступна вся Оперативная память, а в контейнере Cgroup она ограничинает до 128 МиБ, процесс упирается в лимит и убивается ООМ killer. 
2. Каким механизмом Linux Docker ограничивает память?
Докер использует встроенный механизм самой операционной системы Линукс, называется Cgroups
3. Создаёт ли Docker отдельное виртуальное адресное пространство для каждого процесса?
Да, каждый процесс в контейнере это обычный процесс со своим вирутальным адресным пространством, Докер ограничивает ее через команду cgroup 
4. Чем ограничение памяти контейнера отличается от размера виртуальной памяти 
процесса? 
Лимит это ограничение на физическую память (резидентную) которую cgroup может использовать.
Вирутальное пространство процесса может быть намного больше виртуальной памяти, но физически в оперативной памяти эти гигабайты не занимаются
